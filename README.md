# Da Raiz à Mesa

O **Da Raiz à Mesa** é um site desenvolvido para mostrar a trajetória dos alimentos desde o campo até chegarem à mesa do consumidor. O projeto tem como objetivo conscientizar as pessoas sobre a importância da agricultura, do trabalho dos produtores rurais e do consumo consciente.

No site, os usuários podem aprender sobre as etapas da produção dos alimentos, conhecer curiosidades sobre o agronegócio e utilizar uma ferramenta interativa para refletir sobre seus hábitos de consumo.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Apresentação da jornada do alimento
- Informações sobre consumo consciente
- Curiosidades sobre o campo e a agricultura
- Calculadora simples de impacto
- Layout responsivo e interativo

Este projeto foi criado com o objetivo de unir informação, conscientização e tecnologia em uma experiência simples e educativa.
